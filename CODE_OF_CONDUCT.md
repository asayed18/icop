# Code of Conduct

## Our Standards

We are committed to a welcoming, respectful, and technically constructive
community. Examples of positive behavior include empathy, clear feedback,
respect for differing experience levels, and attention to user privacy.

Unacceptable behavior includes harassment, discrimination, sexualized
language or imagery, threats, doxxing, publishing private media, and sustained
disruption of project spaces.

## Project-Specific Care

This project concerns sensitive-content detection. Discussions must remain
clinical and relevant. Do not post explicit imagery, private videos, or links
to exploitative content. Use synthetic descriptions and sanitized fixtures.

## Enforcement

Maintainers may edit or remove contributions that violate these standards and
may temporarily or permanently restrict participation. Report conduct concerns
privately through the contact methods on the
[maintainer's GitHub profile](https://github.com/asayed18). Do not use a public
issue when a report contains private or identifying information.

## Scope

This policy applies in project spaces and when representing the project in
public spaces.
