# Support

Use [GitHub Discussions](https://github.com/asayed18/vlc-iclean/discussions) for
installation help, configuration questions, and general troubleshooting.

Use the issue templates for reproducible bugs and feature requests. Use
[private vulnerability reporting](https://github.com/asayed18/vlc-iclean/security/advisories/new)
for security concerns.

When requesting help, include your operating system, VLC version, plugin
version or commit, processing backend, ONNX provider, and sanitized logs. Never
upload explicit media, private videos, credentials, or identifying file paths.
